User flows

A user flow shows every screen in a journey through a service as a small wireframe, joined by arrows, with the live and prototype address of each page.

Example Desktop screens only

    {{ ufStep({ "type": "text", "title": "Find your land", "live": "/find-land", "prototype": "/example/find-land" }, 1) }} {{ ufStep({ "type": "map", "title": "Map of your land", "live": "/map", "prototype": "/example/map" }, 2) }} {{ ufStep({ "type": "checkbox", "title": "Type of trees", "live": "/tree-types", "prototype": "/example/tree-types" }, 3) }}

Use a user flow to:

  • see a whole journey on one page, on desktop and mobile
  • open any page in the prototype
  • find the address of a page on the live service
  • talk through a journey in research, design crits or show and tells

User flows are built into the GOV.UK Prototype Kit, so they link straight to your prototype’s pages. They’re shared across Defra so teams draw journeys the same way.
