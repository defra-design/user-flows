How to read a user flow

Each screen in a user flow is shown as a step. Steps are joined by arrows to show the order the user sees them in.

Not every step has a live address, prototype link or note. If a page is not on the live service yet, or has not been built in the prototype, that part is left out.

Following a journey

Each grey box is one journey. Read it from left to right, following the arrows. When a journey is too long to fit across the page, it carries on from the left on the next line.

What the wireframes show

The screens are simple wireframes, not designs. They show the type of page and its main parts, so you can recognise it quickly. They do not show the real words on the page.

Key to the wireframes
In the wireframe What it means
A heading
Body text
A link
A button
A text box or other form field
The blue header used on full screen map pages

To see every kind of screen, go to screen types.

Changing what you see

Use the buttons at the top of a user flow to show:

  • Desktop – desktop screens only, which fits more steps on each line
  • Mobile – phone screens only
  • Desktop and mobile – both, side by side

The user flow remembers your choice next time you open it in the same browser.

Printing

Select Print to print the user flow or save it as a PDF. Each journey is kept on one page where it fits. The buttons, header and footer are left out.

For a wall or a workshop, choose Desktop before you print, and set your printer to landscape.
