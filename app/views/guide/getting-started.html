Getting started

A user flow is one file in your prototype. You change it by editing two lists at the top of the file.

If your prototype does not have a user flow yet, first add a user flow to your prototype.

Where the user flow lives

In this repository, the example user flow is app/views/example/user-flow.html. You can view it at /example/user-flow.

In your prototype, it is wherever you put it, such as app/views/user-flow.html. If your prototype has versions, each version has its own, like app/views/v2/user-flow.html.

What to change in the file

Only edit the two lists near the top. Everything else draws the page.

How the lists are written

The lists use a format like JSON. You do not need to know it well, but you need to keep to a few rules or the page will not load:

  • put every name and value in double quotes, like "title": "Results page"
  • put a comma after every item in a list except the last one
  • keep the brackets in pairs – every { needs a } and every [ needs a ]

The easiest way to add something is to copy a line that already works and change it.

If the page stops loading after a change, see if the page does not load.

Using AI to edit a user flow

The repository includes 2 skills for AI coding assistants, such as GitHub Copilot or Claude Code. They are in the .github/skills folder:

  • create-user-flow – add a user flow to a prototype, or to a new version of one
  • edit-user-flow – add, remove or change steps, journeys, pages and screen types

Copy the .github/skills folders into your prototype, then ask your assistant something like “add a contact details step after the results page in the user flow”. Check the user flow in your browser afterwards.
