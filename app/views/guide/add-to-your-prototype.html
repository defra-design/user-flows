Add a user flow to your prototype

You can add a user flow to any prototype made with the GOV.UK Prototype Kit. You copy 2 files, then change one of them to describe your service.

If you use an AI coding assistant, the create-user-flow skill does these steps for you. See using AI to edit a user flow.

1. Copy the files

Get the files from the user flows repository and copy them into your prototype, in the same places:

File What it does
app/views/includes/user-flow/wireframes.njk Draws the wireframes, steps and styles. You do not need to change it.
app/views/example/user-flow.html The user flow page. Put it in the folder with your prototype’s pages, for example app/views/user-flow.html or app/views/v2/user-flow.html.

The Prototype Kit shows the page at the same address as the file, without .html, for example /v2/user-flow. You do not need to add a route.

2. Describe your service

In your copy of user-flow.html:

  1. Change serviceName to the name of your service.
  2. Replace the example journeys with your own steps.
  3. Replace the example pages outside the main flow, or delete them all to leave an empty list: {% raw %}{% set otherPages = [] %}{% endraw %}.
  4. Point each prototype value at a page in your prototype – see linking to prototype pages.

Open the page in your browser to check it loads. If it does not, see if the page does not load.

3. Link to it

Add a link to the user flow from your prototype’s home page, so your team and stakeholders can find it.

Prototypes with versions

If your prototype keeps each version in its own folder, give each version its own user flow. When you make a new version:

  1. Copy user-flow.html from the previous version’s folder into the new version’s folder.
  2. Update the steps for anything that has changed in this version.
  3. Check that the prototype links point to pages that exist in the new version.
  4. Link to the new user flow from your home page.

You do not need to copy wireframes.njk again. Every user flow in the prototype uses the same one.

The guide

You do not need to copy this guide into your prototype. Link to it instead, so everyone uses the same, up-to-date version.
