Adding a screen type

If none of these look like your page, use the closest one for now. A designer can add a new type to the shared file app/views/includes/user-flow/wireframes.njk. It then appears in every user flow in the prototype and on this page.

To add one, ask your AI coding assistant to use the edit-user-flow skill (see using AI to edit a user flow), or follow the notes at the top of the shared file:

  1. Draw the screen in the ufScreen macro, using the existing lines, headings and buttons.
  2. Add any new styles to ufStyles, for desktop and mobile.
  3. Add the type to the ufScreenTypes list, with a name and what it’s for.
  4. Check it fits: desktop screens are 104px tall and mobile screens are 148px. Anything below that is cut off.

If your new screen type would be useful to other teams, share it in the user flows repository so everyone can use it.
