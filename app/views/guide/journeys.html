Journeys

A journey is one grey box of steps joined by arrows. Most user flows only need the main journey.

When to add a journey

Add a journey when

  • the route is different from start to finish, like a returning user who signs in
  • the route ends somewhere else, like a user who is not eligible – see the example user flow

Do not add a journey when

  • the route is only different for one step, then joins the main journey again – use a choice step
  • the user can visit an extra page and come back – add it to pages outside the main flow

This stops the same steps being repeated in several journeys, which makes the user flow longer and harder to keep up to date.

Adding a journey

Copy an existing journey block in the journeys list, give it a new heading and change the steps.

Example A made-up journey for a returning user

Returning user

    {{ ufStep({ "type": "signin", "title": "Sign in", "live": "/sign-in" }, 1) }} {{ ufStep({ "type": "dashboard", "title": "Your requests", "live": "/requests" }, 2) }} 
{
  "heading": "Returning user",
  "steps": [
    { "type": "signin",    "title": "Sign in",       "live": "/sign-in" },
    { "type": "dashboard", "title": "Your requests", "live": "/requests" }
  ]
},

Journeys are shown in the order they are in the list. Put a comma between journey blocks, but not after the last one.
