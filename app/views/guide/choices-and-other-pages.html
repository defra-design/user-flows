Choices and other pages

Not every journey is a straight line. Some steps give the user a choice, and some pages can be visited from more than one place.

When the user chooses one of several screens

Sometimes the user can pick one of several screens at the same point in a journey. These screens are shown side by side in a dashed box.

Example Adding the planting area

    {{ ufStep({ "type": "map", "title": "Map of your land", "live": "/map", "note": "User chooses how to add the planting area" }, 6) }} {{ ufChoiceStep({ "choice": "Add the planting area", "options": [ { "type": "draw-polygon", "title": "Draw the area", "live": "/map" }, { "type": "draw-square", "title": "Add a square", "live": "/map" }, { "type": "upload", "title": "Upload a boundary file", "live": "/upload" } ] }, 7) }} {{ ufStep({ "type": "checkbox", "title": "Type of trees", "live": "/tree-types" }, 8) }}

In this example:

  1. At step 6, the user is on the map.
  2. At step 7, they choose one way to add the planting area. The first option says “choose one” and the others say “or”.
  3. Whichever they chose, they all go on to step 8.

The options in the box all count as one step, so the step numbers carry on as normal afterwards.

Pages outside the main flow

Some pages are not part of the journey in a set order. The user might open them from several places, or might not need them at all. For example:

  • help pages
  • guidance, such as the rules for a grant
  • optional pages, such as reading the grant rules from the grant estimate page

These are shown at the bottom of the user flow, in a dashed box called Pages outside the main flow. They have no arrows or step numbers. Instead, each one lists the pages that link to it.

If a page in the main journey links to an optional page, its note usually says so. For example, the grant estimate page says the user can optionally read the grant rules.
