Linking to prototype pages

Each step can show two addresses: where the page is on the live service, and a link to it in the prototype.

Prototype links

The prototype field can be written in two ways. For a user flow in app/views/example/, like the example user flow:

You write It links to Use it for
"map" /example/map A page in the same folder as the user flow. Use this most of the time.
"/v2/upload" /v2/upload A page in another folder, such as an older version. Start with a slash.

Leave out the .html at the end. The link uses the name of the file in the folder, so "eligibility" links to app/views/example/eligibility.html.

Before adding a link, check the page exists in the folder. If it does not, leave prototype empty until the page is built.

Live addresses

The live field is only ever shown as text, not a link. You can use placeholders for parts that change, like /applications/[reference].

Only add a live address if you know it. Leave it empty for pages that are not on the live service yet.
