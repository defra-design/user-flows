Choice steps

Use a choice step when the user picks one of several screens at the same point in a journey, then carries on the same way whichever they picked.

When to use a choice step

Use a choice step when

  • the user must go through one of the options to carry on
  • all the options lead to the same next step
  • there are 2 to 4 options

Do not use a choice step when

  • the page is optional – add it to pages outside the main flow
  • the options lead to different journeys – add a journey
  • an option is more than one screen long

How to write a choice step

A choice step goes in the steps list like any other step. Instead of a type, it has:

Fields in a choice step
Field What it does Needed?
choice A short name for the choice. It is not shown on the page, but screen readers read it out. Yes
options A list of the screens the user can choose between. Each one is written like a normal step. Yes

The options count as one step, so the steps after it are numbered as normal. The first option is labelled “Step 7 – choose one” and the others “or” – this is done for you.

Brackets and commas

A choice step has more brackets than a normal step. The highlighted ones are easy to miss:

{ "choice": "Add the planting area", "options": [
  { "type": "draw-polygon", "title": "Draw the area" },
  { "type": "draw-square",  "title": "Add a square" },
  { "type": "upload",       "title": "Upload a boundary file" }
] },
  • put a comma between options, but not after the last one
  • close the options with ], then the step with }
  • put a comma after the whole step if another step follows it
